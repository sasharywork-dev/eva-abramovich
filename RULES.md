## 0. Как работаем (процесс)

- **Перед тем как создавать новый визуальный элемент (иконку, кнопку, декоративный узел) —
  спросить, а не придумывать молча.** В частности: сначала проверить, нет ли уже готового
  паттерна/актива в другом месте сайта, который нужно переиспользовать, — и если решения нет
  ни там, ни там, спросить, что и как делать, прежде чем рисовать что-то от руки.
  Нарушение: в мобильное меню молча добавлены нарисованные с нуля иконки Telegram/WhatsApp,
  хотя в «Записаться» иконок для них вообще не было (там просто текст) — стоило спросить,
  каким должен быть новый элемент, а не додумывать самому.

## 1. Факты и содержание

- **Возраст 18+** — убрано отовсюду (и из маркетинга, и из «с кем работаю»).
- **Город — Тбилиси** (не Екатеринбург). Адрес/район не указываем, только «онлайн, очно в Тбилиси по договорённости».
- **Цена — 2 500 ₽** за сессию.
- **Длительность сессии — 50–60 минут** (было «50–55»).
- **Частота — 1 или 2 раза в неделю**, обсуждается индивидуально.
- **Первая встреча платная**, проходит на общих условиях. На сайте это отдельно **не проговариваем**.
- **Секция «Ограничения» / «с кем не работаю» — убрана полностью**, вместе с кризис-строкой. Для психолога общего профиля звучит оборонительно.
- **Каналов, публикаций, выступлений у Евы нет** — блок соцдоказательства не делаем.
- **Секция «Обо мне»**: образование (УрФУ, клиническая психология, специалитет, выпуск 2025) + «регулярные супервизии и личная терапия». Без цифр (год начала практики, часы). Подпись «Практика» заменена на «Супервизия» (Ева просила убрать слово «практика»). Тексты hero и «Обо мне» — дословно от Евы (правки 2026-09).
- **Цитата Карен Хорни** — отдельной секцией, полноэкранный индиго-фон.
- Аналитику Ева настроит сама позже — в [BACKLOG.md](BACKLOG.md).

## 2. Тон и текст

- Ориентир по тону — rationaldays.by: позиционирование через **специализацию**, а не через атмосферу.
- **Регистр обычный, без КАПСА.** Ни подписи, ни заголовки не набираем прописными — сайт получается «кричащий». Иерархия — размером и цветом.
- Заголовок секции **называет её содержание** («С чем работаю», «Стоимость»), а не приглашает («Когда хочется что-то изменить»).
- **Длинное тире (—) в текстах сайта не используем** — это «AI-tell». Только точки, запятые, двоеточия, списки. Диапазоны — через дефис (`50-60`), не через тире.
  - Исключение: тире внутри канонической цитаты Хорни (правильная русская пунктуация).
- **«Эпиграф»** как подпись над цитатой — не пишем.
- Списки — короткими строками, без пояснительного абзаца к каждому пункту.
- Подпись, которая «висит в воздухе» (например «Готовить развёрнутый рассказ… не нужно»), нужно **выделять** — крупнее, индиго-цветом, как отдельную реплику.
- Эйброу (мелкая подпись перед контентом секции) должна быть **хорошо видна** — не блёклый серый.

## 3. Дизайн-направление (эволюция)

Итоговое направление: **спокойная редакционная вёрстка**, ориентир по раскладке — **twofoldny.com**.

Пройденные и отменённые варианты:
1. Тёплая кремово-терракотовая (первая версия) — отменено.
2. Бродшит-система из `DESIGN (1).md` (чёткие линейки, прямоугольники, ноль скруглений, сплит-заголовки, вертикальный текст) — отменено, «слишком».
3. Карточная вёрстка с тенями — отменено, «слишком SaaS».
4. **Текущее:** тёплая почти-белая бумага, чёрный текст, один акцент индиго, волосяные линейки и воздух вместо теней и коробок.

Правила текущего направления:
- **Только светлая тема.** Тёмной темы нет.
- **Убираем тени** — не SaaS-сайт.
- **Минимальное скругление** (радиус ~4px).
- **Убираем разделительные линии** между секциями, **паддинги секций больше**.
- **Белые карточки на бежевом не сочетаются** — если карточка нужна, тёплый оттенок из того же семейства, не чистый белый.
- **Меньше карточек** — там, где можно, группируем воздухом и волосяными линейками, а не коробками.
- Шрифт **Lebowski by Pragmatica** — не подошёл, откатили на Inter.
- Стрелка в кнопках/ссылках — рукописная иконка `images/arrow-ur.svg` (через CSS mask, наследует цвет).
- Если для секции не хватает фото, которое я бы сгенерировал — ставим **размеченный плейсхолдер** (`<!-- TODO -->` + видимый слот), Ева вставит реальное.

## 4. Технические правила

- Стек: чистые HTML / CSS / JS, без сборки и фреймворков. Файлы: `index.html`, `css/style.css`, `js/main.js`.
- **Весь CSS в rem.** Корневой `font-size` плавает по ширине вьюпорта:
  ```css
  html { font-size: 1rem; }
  @media screen and (max-width: 1440px) { html { font-size: calc(0.00007284079084285411rem + 1.1110301768990636vw); } }
  @media screen and (max-width: 479px)  { html { font-size: calc(0.0012019230769234612rem + 4.26153846153846vw); } }
  ```
  Волосяные линейки (`1px`) и брейкпоинты медиазапросов остаются в px.
- **Контейнер — max 1440px**, по центру. Фоны секций во всю ширину, контент капается на 1440 (`padding-inline: max(gutter, (100% - 1440px) / 2)`).
- **Любую присланную картинку сразу жмём** в **AVIF** через ffmpeg (`libsvtav1`) до **250–400 КБ максимум**, с минимальной потерей качества. Не спрашивая — это правило по умолчанию.
  ```bash
  ffmpeg -i <исходник> -vf "scale=2400:-2" -c:v libsvtav1 -preset 3 -crf 14 -pix_fmt yuv420p10le images/<имя>.avif
  ```
  `crf` подбирать под целевой вес: 14 — почти без потерь, 18–22 — если не влезает в 400 КБ. Ширина 2400px под retina; для мелких блоков меньше.
  Исходники складывать в `backup/source/`, из корня убирать.
- В целом шрифты крупнее, но **не у больших заголовков** — они норм.
- Достаточная контрастность текста (тёмный тёплый серый для основного текста, не блёклый).
- **Вёрстка резиновая — отдельной «таблет»-версии нет.** На планшете, включая портретный iPad
  (768px), раскладка та же, что на десктопе — плавающий `rem`-корень и `max-width: 1440px`-контейнер
  сами растягивают/сжимают её без надобности в отдельных правках под ширину планшета.
  Единый мобильный порог — **`620px`** (было раздроблено на `860`/`760`/`620`/`560`, лишние
  `860`/`760` убраны и слиты в `620`, чтобы бургер-меню, одноколоночные грид-секции и т.п. не
  включались на планшетах). Мобильные переопределения (`@media (max-width: 620px)`, и `560px`
  для точечной подстройки внутри уже мобильного диапазона) нужны только под действительно узкий
  портретный экран телефона — не создавать под таблет отдельную промежуточную раскладку и не
  подстраивать её отдельно в Studio (Device Manager: Desktop и Tablet должны выглядеть одинаково).

## 5. Секции — конкретные решения

### Герой
- **Фото на всю секцию как фон** (`Section1.png` → `images/hero.avif`), позиция `right center` — Ева справа в кадре.
- Портрет-карточки в герое **нет**.
- Текст слева поверх светлой части фото, **градиент-скрим** слева: белый фон фото перетекает в тёплый `#f4f2ec`.
- Мобилка: фото сверху, текст внизу над кремовой заливкой.

### Цитата Хорни
- Полноэкранный индиго-фон `#1F2CAA`.
- По макету Figma (ryabkov.work, node 2020:32): Inter 400, **54.4px / line-height 1.3 / tracking −0.02em**, белый.
- Текстовый блок шире — до ~72rem (~1143px).
- «Карен Хорни» — 14px, `rgba(255,255,255,.66)`, отступ 40px.

### «С чем работаю» (Запросы) — вёрстка по monolog (bymonolog.com FAQ)
- **Левый сайдбар**: метка «● Запросы» сверху, снизу (прижато к низу списка) — фото + текст-приглашение + кнопка «Написать мне». Сайдбар растянут на высоту списка.
- **Правая колонка**: заголовок + под ним с большим отступом список FAQ.
- Строки: **пунктирная линия** сверху каждой, вопрос слева, полый кружок справа.
- **Открывается только одна карточка за раз** (аккордеон).
- **Ховер**: фон → индиго, текст → белый мгновенно; текст едет вправо, кружок влево; при уходе мыши фон и цвет **гаснут медленно** (~0.75s) — при проведении по всем карточкам остаётся затухающий трейл.
- **Открытие по клику**: заливается **вся карточка** индиго (не только верх), текст и кружок белеют. Плавное заполнение, без топорного мигания при закрытии (класс `.closing` держит заливку весь коллапс).
- Паддинги в карточках уменьшены на 25% от исходных.
- Иконки-звёздочки перед пунктами убраны.
- Тексты — от Евы (правки 2026-09): 6 тем (Отношение к себе, Тяжелые эмоциональные состояния, Отношения, Жизненные кризисы и выбор, Зависимость от других, Поиск себя), под списком «А также другие запросы для индивидуальной терапии». Утрата/горе убраны. FAQPage-схема повторяет эти тексты.

### Стоимость
- Было «очень тупо» (три висящих блока). Переработано.
- Ориентиры формата: rationaldays.by (цена простыми строками), редакционные подборки.
- Текущее: шапка секции одной строкой (крупная цена + «Индивидуальная сессия, 50–60 минут» + кнопка «Записаться» справа), ниже — список «подпись → значение» (Формат / Частота) с воздухом без линеек, ещё ниже — «Перенос и отмена» тем же аккордеоном, что в «С чем работаю».

### Обо мне
- Секция на **весь экран** (`min-height: 100svh`), фото кабинета (`images/room.avif`) — фоном на всю секцию.
- Контент прижат **к низу** (`display: flex; align-items: flex-end`).
- Фото — не `background-image`, а абсолютный `<img>` с `object-fit: cover` (сохраняет `alt`, ленивую загрузку, картиночный конвейер браузера).
- Поверх фото — **градиент-скрим** снизу вверх (тёмный → прозрачный), чтобы текст читался. Текст в этой секции светлый.

### Как начать
- По макету Figma (ryabkov.work, node 2025:25): **свободная россыпь** трёх шагов по диагонали, не ровный ряд из 3 колонок.
- Каждый шаг: иконка 64px (Streamline Freehand — карандаш / часы / реплики, индиго) + заголовок (Inter 25.6px, ink) + текст в 2 строки с `<br>` (Inter 16px, ink-soft).
- Заголовок «Как начать» — Inter 86.4px / lh 1.03 / tracking −0.025em, индиго.
- Между шагами — лёгкие рукописные стрелки-закорючки (`arrow-ur.svg` через mask, opacity ~0.55), только на десктопе.
- Реплика «Готовить развёрнутый рассказ к первой встрече не нужно» — справа снизу, индиго, ~25.6px, ширина ~24ch.
- Мобилка: чистый вертикальный стек, иконка слева от текста.

### Шапка / навбар
- **Прогрессивный градиент + блюр в стиле Apple**, не сплошной цвет.
- `::before`-слой: `backdrop-filter: blur`, градиент-заливка сверху вниз, и тот же градиент как `mask` — размытие и подложка плавно сходят на нет к низу.
- Фолбэк на `prefers-reduced-transparency` / `prefers-contrast` — плотная плашка.

### FAQ / аккордеоны в целом
- Мягкая анимация открытия и закрытия (плавная высота, ~320/300мс, пружинная кривая), гасится при `prefers-reduced-motion`.

## 6. apple-design (применяли по запросу)

- Отклик на нажатие мгновенный (`:active` на всех интерактивах).
- Трекинг типографики зависит от кегля; тело — около 0, дисплей — отрицательный.
- `prefers-contrast: more` уплотняет линейки и приглушённый текст.
- Прогрессивный блюр навбара (см. выше).

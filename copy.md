# Копирайт сайта (экспертный регистр)

Основа: авторский текст Евы. Правки по [website-rules.md](website-rules.md).
Ориентир по тону: rationaldays.by, позиционирование через специализацию, а не через атмосферу.

**Приёмы:**
- Заголовки называют содержание секции. Никаких «Когда хочется что-то изменить», «Место, где можно быть собой».
- Запросы: короткими строками по 3–5 слов, без пояснительных абзацев.
- Объём текста сокращён примерно вдвое.
- Прайс таблицей, высоко на странице.
- Тон сдержанный, без утешающей интонации. Словарь Евы сохранён.
- В текстах сайта не используем длинное тире. Только точки, запятые, двоеточия. Исключение: тире внутри канонической цитаты Хорни.

Открытых вопросов к Еве нет. Можно переходить к дизайну.

## Что выбросили и почему

| Убрано | Причина |
|---|---|
| «Место, где можно быть собой» | заголовок-настроение вместо позиционирования |
| «Когда хочется что-то изменить» | мягкая интонация, не называет содержание секции |
| «Человек рядом» | не несёт информации |
| Семь абзацев-пояснений к запросам | правило 7: перегрузка вместо ясности |
| «Не обязательно сразу распутывать всё» | утешение, заменено одной фактической строкой |
| Три абзаца про «путь узнавания» | оставлена только цитата Хорни, отдельной секцией-эпиграфом (03) |
| Четвёртый шаг «Двигаемся дальше» | не про начало работы |
| Секция «Ограничения» + кризис-строка | оборонительный тон, убрано полностью |
| Длинное тире во всех текстах сайта | «AI-tell», просьба Евы |

## Решено

- Возраст 18+: убрано.
- Город: Тбилиси, без адреса.
- Цена 2 500 ₽, сессия 50–60 минут, 1 или 2 раза в неделю. Первая встреча платная, на сайте это не проговариваем.
- Правила переноса: формулировка смягчена, условие сохранено.
- Секция «Ограничения» и кризис-строка: убраны полностью.
- Каналов и публикаций нет: блок соцдоказательства не делаем.
- Секция 06 «Обо мне»: образование + «регулярные супервизии и личная терапия», без цифр.
- Цитата Хорни: отдельной секцией (03), как у rationaldays.
- Длинное тире в текстах сайта не используем.
- Аналитика: в [BACKLOG.md](BACKLOG.md), Ева настроит позже.
